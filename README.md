# Customer Service Performance Dashboard

## Overview
An Excel portfolio project analysing 240 fictional customer service tickets from Q1 2026.

## Objectives
- Monitor customer satisfaction (CSAT) and first-contact resolution (FCR).
- Track ticket volume by channel and issue category.
- Review response time, resolution time and escalation rate.
- Compare ticket volumes and service outcomes across agents.
- Present operational indicators in a management-friendly dashboard.

## Workbook contents
- **Dashboard:** KPI cards, charts, service efficiency measures and agent comparison.
- **Ticket Data:** 240 fictional ticket records.
- **Analysis:** formula-driven KPI calculations and channel/category/agent summaries.
- **Read Me:** instructions, metric definitions and data disclaimer.

## Tools
Microsoft Excel, Excel Tables, formulas and charts.

## Data disclaimer
All ticket records and agent names are fictional and generated for demonstration purposes. No real customer or employer information is included.

## Portfolio skills demonstrated
Customer experience analytics, KPI reporting, complaint monitoring, operational performance analysis, Excel data management and dashboard communication.
